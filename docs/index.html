How it works

  • Template: any fillable (AcroForm) PDF — the built-in field lister shows the exact field names to use as column headers

The read-back (why this exists)

Every produced PDF is re-opened and every value compared against the spreadsheet row it came from. A row that fails is named in the report — the batch only passes when every row verifies. Columns with no matching field, and fields with no column, are both listed in the open. Nothing is silently dropped.
